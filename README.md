🧪 Tests Next.js (Vitest + Playwright)

Esse projeto eu criei pra estudar e praticar testes em aplicações modernas usando Next.js.
Queria sair só do “funciona no meu PC” e começar a trabalhar com algo mais próximo do que é usado no mercado.

Aqui eu explorei tanto testes unitários quanto testes end-to-end (E2E), usando ferramentas bem populares hoje.

🚀 Tecnologias utilizadas
▲ Next.js
⚛️ React
🧪 Vitest
🎭 Playwright
🟨 JavaScript / TypeScript
💻 Sobre o projeto

A ideia foi montar uma base simples, mas bem estruturada, pra testar diferentes cenários dentro de uma aplicação.

🧪 Testes com Vitest

Usei o Vitest pra testar:

Funções isoladas
Componentes React
Regras de negócio
🌐 Testes com Playwright

Aqui eu simulei o comportamento real do usuário:

Navegação entre páginas
Cliques e interações
Fluxos completos da aplicação
🎯 Por que fiz esse projeto?

Queria evoluir em pontos que normalmente a gente ignora no começo:

Garantir que o código realmente funciona
Evitar bugs em alterações futuras
Entender como projetos profissionais lidam com testes
Me preparar melhor pra trabalhar em equipe
🧠 O que eu aprendi

Esse projeto me ajudou bastante a entender:

Como configurar testes em projetos com Next.js
Diferença prática entre testes unitários e E2E
Como simular ações reais de usuários
Como organizar testes dentro do projeto
A importância de escrever código já pensando em testabilidade
⚙️ Como rodar o projeto
# Clone o repositório
git clone https://github.com/seu-usuario/tests-nextjs-vitest-playwright.git

# Entre na pasta
cd tests-nextjs-vitest-playwright

# Instale as dependências
npm install
▶️ Rodando a aplicação
npm run dev
🧪 Rodando os testes
Testes unitários
npm run test
Testes E2E
npx playwright test
